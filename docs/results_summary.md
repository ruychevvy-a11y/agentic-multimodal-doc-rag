## 作答路线与路由

### 两条路线的强弱是结构性的

同一套检索、同样的起点 4 页，逐题配对：

| 路线 | 全部（1082） | 单页（501） | 跨页（358） | 起点证据不全（228） | 不可回答（223） |
|---|---|---|---|---|---|
| 一次作答 | 0.643 | 0.707 | 0.488 | 0.243 | 0.749 |
| agent | 0.655 | 0.710 | 0.625 | 0.483 | 0.578 |
| 差值 | +0.012 | +0.004 | **+0.136\*** | **+0.240\*** | **−0.170\*** |

- **总分打平是两个强效应抵消**（+0.012 [−0.011, +0.035]）。
- **留出验证**：agent 提示词在 200 题上选定；其余 882 题上跨页 +0.130\*、起点证据不全 +0.228\*、不可回答 −0.198\*、总分 −0.003。选型 200 题上 +0.078\*，只看选型集会高估约 8 个点。
- **代价是拒答减少**：agent 只有 170 题答「文档中没有」，一次作答 256 题；它会继续检索，没找到证据也作答。
- **开销只落在需要的题上**：25% 触发搜索，平均 1.59 次调用，745 题一次调用结束，平均新增看 0.45 页，兜底 16 题，工具报错 2 次。
- **运行间方差**：同配置跑两次 0.661 / 0.642，11% 的题翻转，只采信超过约 0.02 的差异。

### 路由的效果

10 个作答过程信号 --> 逻辑回归 --> 采信哪条路线：

| 路线 | 全部（1082） | 单页（501） | 跨页（358） | 不可回答（223） |
|---|---|---|---|---|
| 一次作答 | 0.643 | 0.707 | 0.488 | 0.749 |
| agent | 0.655 | 0.710 | 0.625 | 0.578 |
| 检索过才采信 agent | 0.662 | 0.715 | 0.572 | 0.691 |
| **分类器路由** | **0.677** | 0.709 | 0.618 | 0.700 |

- **显著性**：分类器 vs 一次作答 **+0.034\*** [+0.019, +0.050]，vs 手工规则 +0.015\* [+0.003, +0.026]；手工规则 vs 一次作答 +0.019\*；留出 882 题上路由 +0.029\*。
- **口径**：五折 out-of-fold，阈值固定 0.5；只用两路得分不同的 190 题训练（全部放入降至 0.667）；20 种划分均值 0.679（0.675~0.684）。由两份 run 离线组合，不额外调接口。
- **稳健**：199 题重采样 agent，裸 agent 0.720 --> 0.686，手工规则 0.687、分类器 0.702 均不变。
- **标注成本**：每折 10 条 +0.024、20 条 +0.030、全部 +0.034；标注是「两个回答哪个好」，不需要标准答案。
- **学到的权重**：查看页数、调用次数最大且为正；任一方拒答为负。无权重文件时退回「检索过才采信 agent」。

### 失分分布（分类器路由，全量 1082 题）

Acc 0.677，共丢 349.2 分（一次作答 386.2）。排除不可回答题后按去重证据页数分组，与官方分组略有出入。

| 题型 | 题数 | Acc | 丢分 | 占总失分 |
|---|---|---|---|---|
| 跨页 | 370 | 0.619 | 140.9 | 40.3% |
| 单页 | 489 | 0.711 | 141.3 | 40.5% |
| 不可回答 | 223 | 0.700 | 67.0 | 19.2% |

| | 起点证据不全 | 起点已齐全 |
|---|---|---|
| 单页 | 36.1（10.3%） | **105.3（30.1%）** |
| 跨页 | **89.8（25.7%）** | 46.6（13.3%） |
| 不可回答 | — | 67.0（19.2%），该拒答却作答 |

- **跨页是检索问题**：25.7% 失分来自前 4 页装不下；路由后跨页失分 189.5 --> 140.9。
- **单页是作答问题**：证据给全仍答错占 30.1%，是最大单块。
- **不可回答是拒答问题**：19.2%，下表几种修法均未奏效。

| 答案格式 | 题数 | Acc | 占总失分 | | 证据类型 | 题数 | Acc | 占总失分 |
|---|---|---|---|---|---|---|---|---|
| Int | 299 | 0.629 | 31.8% | | Pure-text | 305 | 0.633 | 32.1% |
| List | 151 | 0.549 | 19.5% | | Figure | 304 | 0.646 | 30.8% |
| 不可回答 | 223 | 0.700 | 19.2% | | Table | 218 | 0.678 | 20.1% |
| Str | 250 | 0.740 | 18.6% | | Chart | 178 | 0.618 | 19.5% |
| Float | 159 | 0.761 | 10.9% | | Layout | 119 | 0.707 | 10.0% |

- **Int 比 Float 低 0.13**：整数题多为计数，不是读一个印在页上的数。
- **List 最低 0.549**：列表长度不一致直接 0 分。
- **纯文本占失分最多（32.1%）**：Acc 0.633 与图片 0.646 相近，剩余瓶颈不只在「看不看得见」，也在「读没读懂」。

### 已评估但未采用

| 方法 | 做法 | 结果 |
|---|---|---|
| 提示词加强 | 优先看题目点名的页码，只依据看过的页作答 | 可回答 +0.118\*，不可回答 −0.341\* |
| 级联 | 一次作答说「没有」才交给 agent | 0.637（−0.006）：送进 agent 的 256 题里 167 道是真不可回答，不可回答 −0.188\*，越治越糟 |
| 作答附原文片段 | 逐字引用页面原文，对不上打回一次 | 0.705：答案常在图表里，文本层对不上，误伤正确答案 |
| 定向视觉核验 | 搜过仍给具体答案的题，再看一次引用页图 | 0.684：推翻 6 题只对 1 题，19 道硬答只触发 5 道 |
| 强制先检索 | 没搜就作答时退回，要求先搜 | 0.678，不可回答 0.512：检索是怀疑的结果而非原因 |
| 计算器工具 | 四则运算与取整（`ast` 白名单求值） | 458 道 Int/Float 题 +0.013 [−0.013, +0.041]：失分来自会计口径，不是算术 |
| 证据核验 | 作答后判断是否被引用页支持，不支持改拒答 | 不可回答 +0.122\*、可回答 −0.036\*，打平 |
| 核验 + 再检索 | 核验不过，把理由还给 agent 再搜一轮 | 合并 400 题 +0.026\*，但每题 ¥0.032、p90 54 s |

原文片段、视觉核验、强制先检索的参照是同批 200 题上的 agent 现版（0.717，不可回答 0.585），原始结果在 `answer_experiments/agent_variants/`。

## 成本与延迟（每题）

全量实测，按 qwen3.8-flash 单价折算，不含评测抽答案（约 ¥0.002）：

| 做法 | 花费 | p50 / p90 |
|---|---|---|
| 一次作答 | ¥0.0093 | 8.7 s / 15.0 s |
| agent | ¥0.0172 | 11.1 s / 30.8 s |
| **两条并行 + 路由** | **¥0.0265** | 11.9 s / 31.2 s |
| agent + 核验 + 再检索（未采用） | ¥0.0318 | 21.0 s / 54.2 s |
| 重排一次（30 页候选） | ¥0.0096 | — |
| 追问改写 | < ¥0.001 | 约 1 s |
| 视觉描述（全库一次性） | ¥4.32 / 6522 页 | — |

- **两条并行**：demo 里 agent 答完后最多再等一次作答 10 s，全量模拟仅 1% 等不到；串行则为 20.9 s / 42.7 s。
- **agent 贵在输入**：每多一轮要重发看过的页图，所以限制「累计查看页数」比限制「调用次数」有效。

## 参数与模型选择

| 选择 | 依据 |
|---|---|
| 融合用凸组合，不用 RRF | MP-DocVQA 500 题 r@1：凸组合 0.486 > BM25 0.458 > RRF 0.420 |
| 加 cross-encoder 重排 | MP-DocVQA 上比凸组合 r@1 +0.132\*，MMLongBench 上 +0.116 |
| 重排候选取前 30 | 前 30 与前 50 打平，取 30 省成本 |
| 凸组合权重 (0.25 / 0.55 / 0.20) | 2 折交叉验证重调不显著，两折权重不稳定，维持原值 |
| 作答给 4 页 | k=6 总分 +0.015 不显著，仅证据不全的题 +0.134\*，不可回答更易硬答，成本 +30% |
| 思考预算 1024 token（两条路线共用） | 200 题：默认 0.628 / 1024 0.612 / 关闭 0.613，打平；p90 68.0 s --> 15.6 s |
| 生成模型 qwen3.8-flash | 200 题：3.8-flash 0.629 > 3.7-flash 0.593 > 3.7-plus 0.588 > qwen3-vl-plus 0.568 |
| OCR 用 PP-OCRv6_medium | 更大的 v5_server 答案命中率 −0.042\* 且慢 2.4 倍 |
| 每页不切块 | 证据以整页为单位；切块、换嵌入模型、表格结构化均不显著 |
| 不做检索层路由 | 逐题最优单路 oracle MRR 0.786 ≈ 重排 0.779 |
