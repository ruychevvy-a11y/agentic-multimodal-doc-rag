## 检索

闭域 845 题，即只在题目所属文档内检索。前五行为现行系统的各条路线，末行是同一条重排路线、但正文未拼接视觉描述的对照。

| 路线 | r@1 | r@10 | MRR | 前 4 页含全部金标 |
|---|---|---|---|---|
| BM25 | 0.433 | 0.809 | 0.670 | 0.604 |
| 文本 dense | 0.419 | 0.804 | 0.659 | 0.569 |
| 图像 dense | 0.258 | 0.695 | 0.477 | 0.408 |
| 三路凸组合 (0.25 / 0.55 / 0.20) | 0.465 | 0.847 | 0.711 | 0.632 |
| **+ 重排（前 30 候选，现行系统）** | **0.581** | **0.897** | **0.826** | **0.731** |
| 对照：同一条重排路线，正文不含视觉描述 | 0.526 | 0.872 | 0.776 | 0.675 |

- **重排贡献最大的增益**：凸组合到重排 r@1 +0.116，远超三路融合相对最优单路的增益（+0.032）。第一阶段的作用是把金标页召回到前 30（r@10 已达 0.847），精排交给 cross-encoder。
- **视觉描述的增益次之**：r@1 +0.055\*、前 4 页含全部金标 +0.057\*、MRR +0.050\*。增益集中在图类证据——Figure 类的前 4 页含全部金标 0.601 → **0.718（+0.117\*）**。图表中的信息原本无法被文本检索命中，转写为文字后才进入索引。全库 6522 页描述一次的成本为 ¥4.32。
- **图像 dense 单路最弱，但不宜移除**：加入视觉描述后，它在图类题上的作用已被部分接管，移除后前 30 候选含全部金标仍下降 0.009\*，故保留作为召回兜底。
- **开域检索明显更难**：加入视觉描述之前测得，全库检索时重排 r@1 0.437 / MRR 0.618，凸组合 0.358 / 0.531，BM25 0.309 / 0.452。
- **解析质量不是瓶颈**：同样在加入视觉描述之前的统计中，金标页全为 OCR 页的题 r@1 0.498，全为文本层页的 0.540，差距小于跨页、图类证据等因素。

- **失分主要由跨页与否决定，而非证据类型**：每种证据类型按单页 / 跨页再拆一次后，各类均下降约 0.2；跨页题整体仅 0.487，为最弱的一组。
- **不可回答题准确率最高（0.771）**：模型能够明确给出「文档中不含该信息」，而不是强行编造数值。
- **单页题中图类证据最低**：图片证据 0.662、纯文本 0.628，低于表格的 0.782。前者需要真正读懂图，后者需要在整页文字中定位到具体一小段。
- **失分在检索与作答两端各占约一半**：加入视觉描述之前的拆解结果为，证据给全仍答错 35%、只检索到部分金标页 31%、一个金标页都没检索到 21%、不可回答题判错 12%、标注本身没有有效金标页 2%。
- 解析来源同样不是主因：同一批统计中，金标页全为 OCR 页的题作答 0.561，全为文本层页的 0.605。

## 作答路线与路由

两条路线各跑一次，再由分类器按作答过程择一，是现行系统的作答方式。

### 两条路线的强弱是结构性的

全量 1082 题，在同一套检索下与一次作答逐题配对比较：

| 路线 | 全部（1082） | 单页（501） | 跨页（358） | 起点证据不全（228） | 不可回答（223） |
|---|---|---|---|---|---|
| 一次作答 | 0.650 | 0.712 | 0.488 | 0.241 | 0.771 |
| agent | 0.655 | 0.710 | 0.625 | 0.483 | 0.578 |
| 差值 | +0.005 | −0.002 | **+0.137\*** | **+0.241\*** | **−0.193\*** |

- **总分打平源于两个强效应抵消**，而非没有作用：跨页与起点证据不全两组的增益，恰好被不可回答题的损失冲销。
- **先在 200 题上选定提示词，再在全量上验证**。未参与选型的 882 题单独统计：跨页 +0.144\*、起点证据不全 +0.233\*、不可回答 −0.209\*、总分 −0.004，与全量一致；而选型所用的 200 题上总分 +0.046，明显偏高——**以 200 题为准会高估约 4 个点，本节因此改以全量与留出集为准**。
- **代价是拒答减少**：不可回答题 0.771 → 0.578，agent 倾向于继续检索，即使没有找到证据也会给出答案。四种修法（门控、原文核验、定向视觉核验、强制先检索）均未奏效，见下表。
- **额外开销只落在确有需要的题上**：25% 的题触发了搜索，平均 1.59 次模型调用，745 题一次作答即结束，平均新增查看 0.45 页，兜底强制作答 16 题，工具报错 2 次。
- **运行间方差**：同一配置跑两次 Acc 0.661 与 0.642，22 题（11%）结果翻转，配对区间 [−0.064, +0.026]。因此本节只采信超过约 0.02 的差异。

### 路由的效果

用 10 个作答过程可观察的信号训练逻辑回归，决定每道题采信哪条路线：

| 路线 | 全部（1082） | 单页（501） | 跨页（358） | 不可回答（223） |
|---|---|---|---|---|
| 一次作答 | 0.650 | 0.712 | 0.488 | 0.771 |
| agent | 0.655 | 0.710 | 0.625 | 0.578 |
| 检索过才采信 agent | 0.669 | 0.718 | 0.580 | 0.704 |
| 分类器路由 | **0.680** | 0.713 | 0.615 | 0.709 |

- 分类器路由 vs 一次作答 **+0.030\*** [+0.015, +0.045]；vs 无需训练的手工规则 +0.011 [−0.000, +0.022]，边缘。
- **指标口径**：五折交叉验证的 out-of-fold 值，阈值同样在训练折内选定；只用两条路得分不同的 186 道题训练——得分相同的题对「该选谁」没有信息量，早期把它们一并放入训练时结果由 0.680 降至 0.660。
- **评估方式**：路由是两条已有输出的确定性函数，因此直接由两份 run 文件离线组合得到，未额外调用接口。
- **对生成随机性稳健**：同一批 200 题重新采样一次 agent，裸 agent 由 0.720 降至 0.686，而手工规则 0.704 → 0.704、分类器 0.714 → 0.715 基本不变。
- **标注成本**：学习曲线显示 20 条标注即可达到 +0.025，40 条进入平台；标注内容是「两个回答哪个更好」的成对判断，不需要标准答案。
- **冷启动**：没有权重文件时退回「agent 检索过才采信它」，无需标注即可上线。

### 失分分布（分类器路由，全量 1082 题）

按当前系统的 out-of-fold 结果统计，Acc 0.680，共丢 346.6 分（一次作答是 378.8 分）。本节分组先排除不可回答题，再按去重后的证据页数计，与上面沿用官方判分脚本的分组略有出入（官方按 `evidence_pages` 原始长度计，7 道不可回答题同时计入单页组）。

| 题型 | 题数 | Acc | 丢分 | 占总失分 |
|---|---|---|---|---|
| 跨页 | 370 | 0.619 | 141.1 | 40.7% |
| 单页 | 489 | 0.713 | 140.5 | 40.5% |
| 不可回答 | 223 | 0.709 | 65.0 | 18.8% |

按「检索起点的前 4 页是否已含全部金标」再拆一层，三种题型对应三种不同的病因：

| | 起点证据不全 | 起点已齐全 |
|---|---|---|
| 单页 | 36.9（10.6%） | **103.7（29.9%）** |
| 跨页 | **90.7（26.2%）** | 46.4（13.4%） |
| 不可回答 | — | 65.0（18.8%），该拒答却作答 |

- **跨页题是检索问题**：证据要同时命中两页以上，前 4 页装不下，26.2% 的失分出在这里。agent 正是为此而设（跨页 +0.137\*），路由后跨页失分已从 189.7 降至 141.1。
- **单页题是作答问题**：证据页已经摆在模型眼前，仍然答错，占 29.9%，是最大的单一失分块。
- **不可回答题是拒答问题**：占 18.8%，五种修法均未奏效，见下表。

| 答案格式 | 题数 | Acc | 占总失分 | | 证据类型 | 题数 | Acc | 占总失分 |
|---|---|---|---|---|---|---|---|---|
| Int | 299 | 0.642 | 30.9% | | Pure-text | 305 | 0.626 | 32.9% |
| Str | 250 | 0.725 | 19.8% | | Figure | 304 | 0.626 | 32.8% |
| List | 151 | 0.557 | 19.3% | | Table | 218 | 0.695 | 19.2% |
| 不可回答 | 223 | 0.709 | 18.8% | | Chart | 178 | 0.647 | 18.1% |
| Float | 159 | 0.755 | 11.3% | | Layout | 119 | 0.708 | 10.0% |

- **Int 比 Float 低 0.11**：整数题多为计数（数表格行、数图例项），而不是读取一个印在页面上的数值。
- **List 最低 0.557**：判分规则对列表要求长度一致，少列或多列一项直接计 0，没有部分分。
- **纯文本题与图片题同为 0.626**：在多模态检索与视觉描述之后，最弱的一环反而是不需要多模态能力的纯文本题，说明剩余瓶颈已不在「看不看得见」，而在「读没读懂」。

已完成评估但未采用的方法：

| 方法 | 做法 | 结果 |
|---|---|---|
| 提示词加强 | 提示模型优先查看题目点名的页码，且只依据看过的页作答 | 可回答题 +0.118\*，不可回答题 −0.341\*，更容易强行作答 |
| 先作答再决定是否启用 agent | 一次作答说不出来时才交给 agent | 0.668，不可回答 −0.195\*：门控把真不可回答的题精准送入 agent，越治越糟 |
| 作答附原文片段 | answer 工具要求逐字引用页面原文，对不上则打回一次 | 0.705，打回 79/200：答案常只存在于图表中，文本层查不到，误伤正确答案 |
| 定向视觉核验 | 对「搜索过仍给出具体答案」的题，再看一次引用页页图判断是否被支持 | 0.684，推翻 6 题只有 1 题正确；19 道过度作答的题里仅 5 道触发核验 |
| 强制先检索再作答 | 一次未检索就调用 answer 时退回，要求先 search_pages | 0.678，不可回答 0.512：检索是怀疑的结果而非原因，强制检索反而提供了更多拼凑材料 |
| 计算器工具 | 给 agent 增加一个只做四则运算与取整的 calculate 工具（`ast` 白名单求值，不用 eval） | 458 道 Int/Float 题上 0.707 对 0.694，+0.013 [−0.013, +0.041]：变好 24 道、变差 18 道，原先的失败样例一道未修复——失分来自会计口径与财务定义（common equity 含哪些项、cash ratio 的分母），不是算术执行 |
| 证据核验 | 作答后再调用一次模型，判断答案是否被引用页支持，判定不支持则改为拒答 | 不可回答 +0.122\*、可回答 −0.036\*，总分打平 |
| 核验 + 再检索 | 核验未通过时，将核验理由返回给 agent 并允许其再检索一轮 | 合并 400 题 +0.026\*，但每题成本升至 ¥0.032、p90 54 s |


## 成本与延迟（每题）

全量 1082 题上的实测值。agent 限制思考预算为 1024，一次作答不传该参数、用模型默认思考：

| 做法 | 花费 | p50 / p90 / 最长 |
|---|---|---|
| 一次作答 | ¥0.0130 | 10.4 s / 57.1 s |
| agent | ¥0.0172 | 11.1 s / 30.8 s |
| agent + 核验 + 再检索（未采用） | ¥0.0318 | 21.0 s / 54.2 s |
| 一次作答（默认思考，全量 1082 题基线） | ¥0.0128 + 抽答案 ¥0.002 | 10.4 s / 57.1 s |
| 重排一次（30 页候选） | ¥0.0096 | — |
| 追问改写 | 不到 ¥0.001（一次短文本调用） | 约 1 s |
| 视觉描述（全库一次性） | ¥4.32 / 6522 页 | — |

agent 的成本主要来自重复发送历史：每增加一轮，此前看过的页图都要重新发送一次，因此限制「累计查看页数」比限制「模型调用次数」更有效。

## 参数与模型选择

| 选择 | 依据 |
|---|---|
| 融合用凸组合，不用 RRF | MP-DocVQA 500 题 r@1：凸组合 0.486 > BM25 0.458 > RRF 0.420 |
| 加 cross-encoder 重排 | MP-DocVQA 500 题上比凸组合 r@1 +0.132\*，MMLongBench 上 +0.116 |
| 重排候选取前 30 | 前 30 与前 50 打平，取 30 以节省成本 |
| 凸组合权重 (0.25 / 0.55 / 0.20) | 2 折交叉验证重调不显著，且两折选出的权重不稳定，维持原值 |
| 作答给 4 页 | k=6 总分 +0.015（不显著），增益仅出现在证据不全的题（+0.134\*），不可回答题更容易强行作答，成本增加 30% |
| 思考预算 1024 token | 默认 0.628 / 限制 1024 0.612 / 关闭 0.613，三者打平，但 p90 由 68.0 s 降至 15.6 s |
| 生成模型 qwen3.8-flash | 200 题 Acc：3.8-flash 0.629 > 3.7-flash 0.593 > 3.7-plus 0.588 > qwen3-vl-plus 0.568 |
| OCR 用 PP-OCRv6_medium | 更大的 v5_server 答案命中率 −0.042\* 且慢 2.4 倍 |
| 每页不切块 | 该数据集的证据以整页为单位；切块、更换嵌入模型、表格结构化均不显著 |
| 不做检索层路由 | 逐题选取最优单路的 oracle MRR 0.786 ≈ 重排的 0.779，提升空间有限 |
